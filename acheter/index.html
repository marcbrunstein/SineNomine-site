Ce que vous achetez

Sine Nomine pseudonymise vos documents sur votre ordinateur pour que vous puissiez les utiliser avec une IA ou un service en ligne, puis rétablit les valeurs d'origine dans les résultats. Pseudonymisation et rétablissement s'effectuent entièrement en local ; la table de correspondance reste sur votre ordinateur. 11 881 376 pseudonymes disponibles par projet ; projets multiples avec l'édition Expert. Voir le fonctionnement.

Deux éditions : Standard ou Expert

L'édition Standard (49 € TTC) est destinée à un usage non professionnel. L'édition Expert (149 € HT par poste au tarif de lancement, puis 199 € HT) est destinée à un usage professionnel : si vous utilisez Sine Nomine dans le cadre de votre activité, y compris en tant qu'indépendant ou profession libérale, choisissez l'édition Expert. Dans les deux cas : sans limite de durée, toutes les futures versions incluses. Une licence vaut pour un ordinateur ; l'édition Expert permet de commander plusieurs postes en une seule fois.

Licences groupées (édition Expert). Indiquez le nombre de postes souhaité (de 1 à 100) : le prix est calculé en conséquence (nombre de postes × prix par poste) et vous recevez une seule clé qui permet l'installation de Sine Nomine sur autant d'ordinateurs que de postes commandés. À chaque installation, l'application indique le nombre de crédits de licence restants. Un crédit consommé n'est pas restitué si un ordinateur est remplacé. Au-delà de 100 postes, contactez-nous.

Le paiement est effectué sur la page sécurisée de notre prestataire de paiement, Stripe (Stripe Payments Europe, Ltd., Irlande). Sine Nomine ne reçoit ni ne conserve votre numéro de carte. La licence n'est délivrée qu'après vérification du paiement par notre serveur.

Après le paiement : confirmation, licence et installation

  1. Confirmation. Une fois le paiement vérifié par notre serveur, votre clé d'accès (la licence) vous est envoyée à l'adresse courriel saisie lors du paiement. Elle n'est jamais affichée dans l'adresse d'une page.
  2. Téléchargement. Rendez-vous sur la page Installer, téléchargez l'archive et vérifiez son empreinte.
  3. Installation. Lors de l'installation, saisissez votre clé d'accès : elle est activée avec une connexion Internet, une activation par ordinateur (l'application indique le nombre de crédits restants). Ensuite, Sine Nomine fonctionne hors ligne.

Si le paiement est refusé ou annulé, aucune clé n'est délivrée. Si vous n'avez rien reçu après un paiement abouti, écrivez à contact@sinenomine.app en indiquant l'adresse utilisée pour payer.
