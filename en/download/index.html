Installation (Windows)

  1. Unzip the archive into a local folder, for example C:\SineNomine. Avoid a synchronised folder (Google Drive, OneDrive): your files and the code archive would be transmitted to that service.
  2. Double-click lancer.bat. On first launch, the installation sets everything up: it offers to install Python 3.12 if needed (winget), downloads about 2 GB of models and installs optical character recognition (Tesseract) for scanned PDFs. Allow a fair amount of time, depending on your connection, and an Internet connection.
  3. The interface opens in your browser at http://127.0.0.1:8765/ (a local address, visible only to you). Read and accept the notice, then pick an action from the menu.
  4. Optional: double-click creer-raccourcis.bat to add a Desktop shortcut.

Loading the models takes 20 to 60 seconds each time it starts. Keep the black window open while you use it, and close it to stop Sine Nomine.

Check the downloaded file

In PowerShell, from the download folder, compare the result with the checksum above:

Get-FileHash SineNomine-V0.1.3.8.zip -Algorithm SHA256
