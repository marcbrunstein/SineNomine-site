Get-FileHash SineNomine-V0.1.4.8.zip -Algorithm SHA256

Installation, step by step

  1. Unzip the archive into a local folder, for example C:\SineNomine. Avoid a synchronised folder (Google Drive, OneDrive): your files and the code archive would be transmitted to that service.
  2. Double-click lancer.bat. A black window opens: this is normal, it is what runs Sine Nomine.
    First time only: the installation offers to install Python 3.12 if needed, downloads about 2 GB of components and installs character recognition (Tesseract). This can take a long time depending on your connection: as long as lines scroll in the black window, the installation is progressing.
  3. Enter your access key when the installation asks for it. It is activated with Habeas Corpus's server, and the installation tells you how many more times the key can be used.
  4. Sine Nomine is ready when your browser opens at http://127.0.0.1:8765/ (a local address, visible only to you). Read and accept the notice, then choose an action in the menu.
  5. Optional: double-click creer-raccourcis.bat to add a desktop shortcut.
On later starts, allow 20 to 60 seconds for the models to load before the browser opens. Leave the black window open while you work; close it to stop Sine Nomine.
