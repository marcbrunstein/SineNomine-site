5. Pseudonymisation and anonymisation

Pseudonymisation. Each name is replaced by a random code (for example Personne_KQXMB). The correspondence table and the code archive make it possible to recover the original information and restore the original values in files: within the meaning of the GDPR this is pseudonymisation, not anonymisation. This data contains the original information: keep it separately and securely, or delete it if you do not need it.

Anonymisation. Names are replaced by numbers (Personne_1, Société_1…) and no correspondence table is kept: Sine Nomine keeps no means of recovering the original names from the files produced. This mode does not guarantee that the result is anonymous within the meaning of the GDPR: a text may remain identifiable by cross-referencing (job, place, event, combination of information). Review it before sharing.
