Pseudonymisation and anonymisation

Pseudonymisation. Each name is replaced by a random code (for example Personne_KQXMB). The correspondence table and the code archive (archive_codes.json) make it possible to recover the original information and to de-pseudonymise files: under the GDPR this is pseudonymisation, not anonymisation. These files contain the original information in clear: keep them separately and securely, or delete them if you do not need them.

Anonymisation. Names are replaced by numbers (Personne_1, Société_1…) and no correspondence table or archive is kept: Sine Nomine keeps no means of recovering the original names from the files produced. This mode does not guarantee that the result is anonymous within the meaning of the GDPR: a text may remain identifiable by cross-referencing (role, place, event, combination of information). Proofread it before sharing.
