Où trouver votre clé

  • Après un achat, la clé est envoyée à l'adresse saisie lors du paiement, dans un courriel intitulé « Votre licence Sine Nomine », expédié par contact@sinenomine.app. Conservez ce message.
  • Rien reçu ? Regardez dans les courriers indésirables, puis écrivez à contact@sinenomine.app en indiquant l'adresse utilisée pour payer. Vous n'avez pas à demander une nouvelle clé.
  • Licence groupée : la même clé sert sur chaque poste ; l'installation indique le nombre de crédits restants.

Clé d'évaluation. Pour essayer Sine Nomine avant d'acheter, vous pouvez demander une clé d'évaluation, limitée dans le temps, à contact@sinenomine.app (indiquez votre nom, votre organisation et l'usage prévu).

Installation, étape par étape

  1. Décompressez l'archive dans un dossier local, par exemple C:\SineNomine. Évitez un dossier synchronisé (Google Drive, OneDrive) : vos fichiers et l'archive des codes y seraient transmis à ce service.
  2. Double-cliquez sur lancer.bat. Une fenêtre noire s'ouvre : c'est normal, c'est elle qui fait tourner Sine Nomine.
    Première fois seulement : l'installation propose d'installer Python 3.12 si besoin, télécharge environ 2 Go de composants et installe la reconnaissance de caractères (Tesseract). Cela peut durer longtemps selon votre connexion : tant que des lignes défilent dans la fenêtre noire, l'installation avance.
  3. Saisissez votre clé d'accès quand l'installation vous la demande. Elle est activée auprès du serveur de Habeas Corpus, et l'installation vous indique combien de fois la clé peut encore être utilisée.
  4. Sine Nomine est prêt quand votre navigateur s'ouvre à l'adresse http://127.0.0.1:8765/ (adresse locale, visible de vous seul). Lisez et acceptez l'avertissement, puis choisissez une action dans le menu.
  5. Facultatif : double-cliquez sur creer-raccourcis.bat pour ajouter un raccourci sur le Bureau.
Aux démarrages suivants, comptez 20 à 60 secondes de chargement des modèles avant l'ouverture du navigateur. Laissez la fenêtre noire ouverte pendant l'utilisation ; fermez-la pour arrêter Sine Nomine.
